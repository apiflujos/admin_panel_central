# Ejecucion quinto lote - clones Alegra olivashoes

Operacion sugerida: inactivar clones. No borrar.

- Grupos: 14
- Clones candidatos a inactivar: 16
- Criterio:
  - mismo nombre
  - existe original con `reference`
  - clones sin `reference`, `barcode` ni `code`

## Formato operativo

- `nombre | id original | reference original | ids clones a inactivar`
